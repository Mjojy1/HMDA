# Customer-facing HMDA concepts

Three visual mockups generated with the built-in image tool; exact prompts are
in prompts.json. These images are design explorations. Concept 05 was subsequently selected
and implemented in the existing frontend; see the main README for verification.
The illustrative conversation in the image remains illustrative.

- 04 Customer overview: compact scope controls, an outcome summary, plain-language
  performance explanations and clear paths into detail. Navy/teal sidebar layout.
- 05 Guided analysis: horizontal navigation and a contextual analyst pane, with
  evidence citations and explanations beside results. Recommended base direction.
- 06 Customer review: spacious fairness coverage view with explicit unavailable
  states and progressive explanation, using a quiet evergreen accent.

Metrics depict the existing saved model, not the new training workflow's model.
The ROC curve in 04 is illustrative; 05 contains an example conversation, not
proof of connected live inference. Availability in 06 must be checked against
the actual mounted artifacts during implementation. Sample thresholds do not
by themselves establish statistical reliability. The saved holdout is fixed;
its scope control must not imply evaluation on other years is available.
The heading in 04 refers to a filtered public sample, not a customer's portfolio.
Final copy should use 'Mortgage lending research' to avoid that ambiguity.
